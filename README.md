# ai-launcher

Pixel 風のページャーで構成した、Android 向けのシンプルなホームアプリ（ランチャー）です。

## 特徴

- 左「Discover」/ 中央「Home」/ 右「アプリ一覧」。ショートカットがある場合は Home とアプリ一覧の間に専用ページを表示
- 秒表示付きの大きな時計とカレンダーカードを Home に表示
- ホーム画面に App Widget を自由配置（5 列グリッド、幅・高さのリサイズに対応）
- 下部4枠のドックを編集可能（アプリの変更・削除、Pixel 風アプリフォルダに対応）。ショートカットがある場合は横に専用フォルダを表示
- ショートカットページのドラッグハンドルから、ショートカットを下部ドックの既存フォルダへ移動
- 右のアプリ一覧からアプリをホーム画面へ追加し、ホームから起動・削除
- Chrome などから届く Android のショートカット追加要求を確認して受け入れ、ホームに保存
- 右のアプリ一覧でユーザーカテゴリを作成し、アプリを分類
- Discover 画面に AI メッセージ枠を表示（差し替え可能）
- 常時ダークモード（端末のテーマ設定に関わらず黒背景・白文字で固定）

## ダウンロード / ビルド

Releases は未整備のため、現状はソースからビルドして利用します。

```bash
./gradlew assembleDebug
```

生成された APK (`app/build/outputs/apk/debug/app-debug.apk`) を端末にインストールしてください。

## インストール後の注意

APK をインストール、または上書きインストールしたあとは、必ずアプリを一度強制停止（force-stop）してから起動してください。ウィジェットのレイアウトや状態が正しく反映されないことがあります。

## 使い方

1. 端末のホームアプリ選択でこのアプリを選ぶ
2. 中央画面（Home）が時計・カレンダー・ウィジェット配置エリア
3. 右スワイプでアプリ一覧。ショートカットがある場合は Home とアプリ一覧の間にページが入り、下部バーの「ショート」フォルダからも開けます。左スワイプで Discover 画面
4. アプリ一覧の「＋」からカテゴリを作成。アプリを長押しして「カテゴリを変更」から分類
5. アプリ一覧でアプリを長押しして「ホーム画面に追加」。下部バーの「ショート」フォルダに保存されます
6. Chrome などの「ホーム画面に追加」で受け入れたショートカットも「ショート」フォルダに保存されます
7. ショートカットページで項目右上のハンドルをドラッグすると、下部に既存フォルダが表示されます。追加先フォルダにドロップすると移動し、ショートカットページからは消えます
8. ドックのアイコンを長押しして左右へ動かすと並べ替え、別アプリへ重ねるとフォルダ作成、既存フォルダへ重ねるとアプリ追加が可能
9. ドックのアイコンを上方向へ動かして離すとドックから削除。動かさず離すと補助編集メニューを表示

## 必要環境

- Android 12 (API 31) 以上
- ビルドには AGP 9 系 + Kotlin（Kotlin Gradle Plugin は `kotlin-android` ではなく AGP 組み込みの Kotlin サポートを使用）
